# 🌊 Liquid OS - Феноменальная Интерактивная Система

Полноценная операционная система с liquid glass дизайном, плавными iPhone-подобными переходами и реальным временем.

## 🚀 Возможности

### Backend (Python/FastAPI)
- ✅ **WebSocket** реальное время для всех клиентов
- ✅ **REST API** для получения данных
- ✅ **In-Memory база данных** с демо-данными
- ✅ **Фоновые задачи** (уведомления, обновления погоды)
- ✅ **8 интерактивных приложений** с данными
- ✅ **Броадкаст событий** всем подключенным клиентам

### Frontend (Liquid Glass UI)
- ✅ **Three.js живой фон** с плавающими орбами
- ✅ **Glassmorphism эффект** с blur(40px)
- ✅ **GSAP анимации** как в iPhone (cubic-bezier)
- ✅ **8 приложений**: Chat, Music, Photos, Weather, Notes, Calendar, Tasks, Files
- ✅ **Интерактивные виджеты** на главном экране
- ✅ **Плавающие уведомления** в реальном времени
- ✅ **Haptic feedback** для мобильных устройств
- ✅ **Адаптивный дизайн** для всех экранов

## 📦 Установка

### 1. Установка зависимостей Python

```bash
cd /workspace/liquid_os/backend
pip install -r requirements.txt
```

### 2. Запуск сервера

```bash
python main.py
```

Сервер запустится на `http://localhost:8000`

### 3. Открытие фронтенда

Откройте файл `/workspace/liquid_os/frontend/index.html` в браузере или используйте любой HTTP сервер:

```bash
cd /workspace/liquid_os/frontend
python -m http.server 3000
```

Затем откройте `http://localhost:3000`

## ⚡ Интерактивность

- Клик по задачам отмечает их выполненными
- Данные обновляются в реальном времени через WebSocket
- Уведомления приходят каждые 5 секунд
- Погода обновляется автоматически
- Все изменения синхронизируются между клиентами

## 🛠 Технологии

- **Backend**: Python 3, FastAPI, WebSockets, Uvicorn
- **Frontend**: HTML5, TailwindCSS, GSAP, Three.js
- **Стили**: Glassmorphism, CSS Animations
- **Шрифты**: SF Pro Display (Apple style)
